### 3D Scanning Technologies: Core Principles 3D scanning is about estimating the shape of real objects by collecting enough reliable observations of their surfaces. The method changes, but the core requirements stay the same: visible surface, usable signal, multiple views, alignment, scale, and cleanup. The quality of the scan is more of a function of the time and care you put into prep work and cleanup than the scanning technology itself. --- ### Structured Light A projector casts a known pattern onto the object. A camera sees how the pattern bends across the surface. The scanner calculates depth from that distortion. ![structured light](structured-light-technology.jpg) _Depth comes from how the known pattern deforms._ Best for: matte objects, faces, sculptures, medium-sized parts. --- ### Photogrammetry Photogrammetry uses many overlapping photos. Software finds the same visual features in different images, estimates camera positions, and reconstructs 3D points. ![photogrammetry](photogrammetry.jpg) _Matching the same point from many views lets software triangulate its 3D position._ Best for: textured objects, artifacts, sculpture, architecture, outdoor objects, classroom/makerspace use. --- ### Time-of-Flight / LiDAR LiDAR (Light Detection and Ranging) is an active remote sensing technology that uses pulsed lasers to measure distances. A sensor emits light and measures how long it takes to return. Distance is calculated from travel time or phase shift. ![lidar](lidar.jpg) _Longer return time = farther surface. Shorter return time = closer surface._ Best for: rooms, furniture, bodies, AR, spatial mapping, large objects. --- ### Contact / Probe Scanning A physical probe touches the object at known points. Each contact point becomes a measured coordinate. ```text Probe arm | v (tip) * contact point | ___v___ / \ / object \ \_________/ Each touch records one measured 3D point. ``` Best for: precise measurement, machining, quality control, shiny or transparent objects. --- Common failure causes: | Problem | Why it matters | | ------------------- | ------------------------------------------ | | Shiny surface | Reflections move and confuse measurements | | Transparent surface | Light passes through or refracts | | Black surface | Too little light returns | | Textureless surface | Photogrammetry cannot find enough features | | Thin parts | Edges are hard to resolve | | Repetitive patterns | Software may match the wrong features | | Deep cavities | Not enough line of sight | | Motion | The object changes between views | <!-- ## Laser Triangulation A laser projects a dot or line.
