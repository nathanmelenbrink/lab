### Rhino Commands For Laser Cutting _Rhino works best as a command-line tool. While icons/menu items exist for these commands, it's easiest to just type them and then follow the prompts._ ## Rhino commands for Fusion DXF cleanup and Universal Laser cutting | Command | Use | |---|---| | `Import` | Bring in a DXF, DWG, AI, PDF, or other vector file while keeping the current Rhino file open. Useful for importing Fusion DXFs into a laser template. (Drag and drop also works) | | `Distance` | Measure a known feature to verify scale after import. | | `Scale` | Resize imported geometry if the DXF came in at the wrong scale. | | `Move` | Reposition parts onto the laser bed or material boundary. | | `Rotate` | Reorient parts for grain direction, material efficiency, or laser bed layout. | | `Copy` | Duplicate parts or test cuts. | | `Delete` | Remove unwanted geometry, construction lines, duplicate parts, imported title blocks, or failed cleanup artifacts. | | `Trim` | Cut away portions of curves using other curves as cutting edges. Useful for cleaning overlapping DXF geometry. | | `Split` | Break curves apart at intersections without deleting either side. Useful before manual cleanup. | | `Join` | Combine connected curve segments into closed or continuous curves. Important for clean vector cutting. | | `Explode` | Break blocks, polylines, hatches, or grouped objects into editable pieces. Useful when imported Fusion geometry cannot be edited directly. | | `SelDup` | Select duplicate curves. Essential for Fusion DXFs because stacked lines can cause the laser to cut the same path multiple times. | | `SelOpenCrv` | Select open curves. Useful for finding outlines that should be closed before cutting. | | `SelClosedCrv` | Select closed curves. Useful for checking which profiles are ready for cutting or hatching. | | `SelShortCrv` | Select tiny stray curve fragments. Useful for deleting small artifacts from imports. | | | `CloseCrv` | Close a curve by connecting its endpoints. Use carefully, because it may create a straight closing segment. | | `Print` | Send the file to the Universal Laser driver. Confirm scale, placement, colors, vector/raster settings, and material setup before cutting. | <!-- | `Extend` | Extend curves until they meet another curve.
