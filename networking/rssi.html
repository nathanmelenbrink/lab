## ESP-NOW Proximity Detection with RSSI and NeoPixels ![demo](./rssi.gif) This guide explains how to set up **two ESP32 Dev boards** to estimate proximity using **ESP-NOW** and display it using a **NeoPixel LED strip**. Devices broadcast to each other and use **received signal strength indicator <a href="https://en.wikipedia.org/wiki/Received_signal_strength_indicator">(RSSI)</a>** to estimate distance, which is mapped to red LED brightness (brighter = closer). --- ## What You Need - 2x ESP32 DevKit boards (not C3 or S3) - Arduino IDE (v1.8 or 2.x) - ESP32 board package (tested with 3.2.1) - Adafruit NeoPixel strip --- ## ESP-NOW Requires Explicit Peer Registration (Why It Matters) In ESP32 Arduino Core 3.x, ESP-NOW requires **explicit registration of peer MAC addresses**, even for receiving broadcast packets. This is a change from earlier cores (e.g. 2.0.6), where broadcasts were received without peer setup. If you do not register peers: - `esp_now_send()` might still return 0 - But `OnDataRecv()` will **never be called** **Lesson:** You must register the other device's MAC address using `esp_now_add_peer()`. --- ## Get MAC Addresses First Upload this minimal sketch to each ESP32 board and open the Serial Monitor: ```cpp #include <WiFi.h> void setup() { Serial.begin(115200); WiFi.mode(WIFI_STA); Serial.print("MAC Address: "); Serial.println(WiFi.macAddress()); } void loop() {} ``` Record each MAC address (e.g. `B0:B2:1C:A7:82:FC`). --- ## Upload This Code to Both Boards Replace the `peerMAC[]` value on each board with the **other board's MAC address**. ```cpp #include <WiFi.h> #include <esp_now.h> #include <esp_wifi.h> #include <Adafruit_NeoPixel.h> #define LED_PIN 14 #define LED_COUNT 7 Adafruit_NeoPixel strip(LED_COUNT, LED_PIN, NEO_GRB + NEO_KHZ800); const float A = -40.0; // RSSI at 1 meter const float n = 2.5; // Path loss exponent const float DIST_MIN = 0.2; const float DIST_MAX = 20.0; float lastDistance = DIST_MAX + 1; // Replace this with the MAC address of the other board uint8_t peerMAC[] = { 0xB0, 0xB2, 0x1C, 0xA7, 0x82, 0xFC }; void setup() { Serial.begin(115200); WiFi.mode(WIFI_STA); // Lock Wi-Fi channel (required for stable ESP-NOW) esp_wifi_set_promiscuous(true); esp_wifi_set_channel(1, WIFI_SECOND_CHAN_NONE); esp_wifi_set_promiscuous(false); strip.begin(); strip.show(); Serial.print("My MAC: "); Serial.println(WiFi.macAddress()); if (esp_now_init() != ESP_OK) { Serial.println("ESP-NOW init failed"); return; } esp_now_register_recv_cb(OnDataRecv); esp_now_peer_info_t peer = {}; memcpy(peer.peer_addr, peerMAC, 6); peer.channel = 1; peer.encrypt = false; if (!esp_now_is_peer_exist(peerMAC)) { esp_now_add_peer(&peer); } Serial.println("Setup complete."); } void loop() { const char *msg = "ping"; esp_now_send(peerMAC, (uint8_t *)msg, strlen(msg)); float d = constrain(lastDistance, DIST_MIN, DIST_MAX); float brightness = map(d, DIST_MIN, DIST_MAX, 255.0, 10.0); brightness = constrain(brightness, 10.0, 255.0); uint32_t color = strip.Color((uint8_t)brightness, 0, 0); for (int i = 0; i < LED_COUNT; i++) { strip.setPixelColor(i, color); } strip.show(); delay(1000); } void OnDataRecv(const esp_now_recv_info_t *info, const uint8_t *data, int len) { int rssi = info->rx_ctrl->rssi; float distance = pow(10.0, (A - rssi) / (10.0 * n)); lastDistance = distance; Serial.printf("RECV | RSSI: %d dBm | Distance: %.2f m\n", rssi, distance); } ``` --- ## Will This Work on the XIAO ESP32 (C3)? Mostly **no** — unless you downgrade your board support. ### On XIAO ESP32-C3 (RISC-V): - ESP-NOW is **unreliable** in current (3.x) Arduino cores - Broadcast receive **does not work** - RSSI support is limited or missing ### You can try: - Downgrading to **ESP32 Arduino core 2.0.6** - Using only basic send/receive logic (no dynamic peer registration) ### Recommended: > Use the **original ESP32 XIAO (not C3/S3)** or **ESP32 DevKit** for stable ESP-NOW + RSSI functionality. --- ## Notes on Testing - Use Serial Monitor at 115200 baud - Check that both boards print `RECV` lines - Use a ruler to measure actual distance and compare RSSI --- ## Summary - Use ESP32 Dev boards (not C3 or S3) - Lock both to Wi-Fi channel 1 - Register each other’s MAC addresses - Use ESP-NOW to exchange simple `ping` packets - Extract RSSI and map to brightness on NeoPixel --- ## Working State Checklist - [x] `esp_now_init()` returns `ESP_OK` - [x] `esp_now_send()` returns `0` - [x] `OnDataRecv()` gets called - [x] RSSI prints in Serial Monitor - [x] NeoPixels light up red - [x] Red gets brighter when boards are closer ---
